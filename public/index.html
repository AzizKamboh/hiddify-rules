How to import
  1. File: Hiddify → Settings → Routing → ⋮ → import from file → choose route_rules.json.
  2. Link: click Open in Hiddify, or copy the link and use ⋮ → import from clipboard. Hiddify asks before replacing your rules.
  3. Reconnect from the Home page so the new rules load.

Importing replaces all your routing rules. Hiddify's built-in rules keep their own content (it differs between Windows and Android); only their on/off switch comes from here.
